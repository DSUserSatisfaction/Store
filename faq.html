Frequently asked

Questions & answers

Do you process real orders?

No. This is a frontend demonstration. Real payment and order processing require a commerce platform or custom backend.

Where is my cart saved?

Cart and wishlist information are stored in this browser using localStorage.

Can I change the products?

Yes. Edit the objects in products.js; the catalog and sections update automatically.

Can I publish this on GitHub Pages?

Yes. Upload the folder, enable Pages, and choose the repository branch as the publishing source.
